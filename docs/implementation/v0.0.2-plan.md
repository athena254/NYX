## Research decisions and authoritative references

1. Apply authentication centrally to protected routers, not a rate limiter. Capabilities remain explicit per operation; health/readiness exemptions are enumerated. Preserve loopback local-operator semantics, but never treat a body identity as authentication. FastAPI: https://fastapi.tiangolo.com/tutorial/dependencies/global-dependencies/ and https://fastapi.tiangolo.com/tutorial/bigger-applications/ .
2. Keep ingestion acceptance and assessment scheduling atomic in the same SQLAlchemy transaction; repositories never commit implicitly. Use a durable bounded lease/retry queue, not an in-memory list. SQLAlchemy 2.1: https://docs.sqlalchemy.org/en/21/orm/session_transaction.html .
3. Model method strength separately from support for the exact proposition. A negative/error/skipped observation cannot positively support a completion claim. Bind successful support to artifact, version, environment, relevance and declared time window. Missing/contradictory data is unknown or an explicit gap, not misconduct.
4. Structured test outcomes are additive optional validated fields. New producers should provide explicit outcomes; old simple text artifacts retain narrowly documented compatibility until migrated, with counted/negated/skipped text never guessed into success or failure. Do not silently turn unstructured legacy records into authoritative verification.
5. The model receives all relevant target facts inside an untrusted fence; policy/schema remain trusted. Never interpolate a producer statement into the trusted question. Bound context deterministically and label omitted data; no silent truncation into false certainty.
6. Checkpoint comparison recomputes chain integrity and anchor agreement from the same consistent read; body-only mutations and interior deletion must fail.
7. Windows cannot safely cancel arbitrary Python callbacks in a thread. Use owned process isolation for hard deadlines; explicitly fail closed when a callback cannot be serialized rather than leave runaway threads. Preserve serializable callback compatibility. Python: https://docs.python.org/3.14/library/multiprocessing.html#contexts-and-start-methods and https://docs.python.org/3.14/library/subprocess.html#subprocess.run . If cloudpickle is necessary for supported lambdas/closures, add one pinned reviewed dependency and document trusted-only IPC/same-interpreter use; do not accept external pickle data. Primary source: https://github.com/cloudpipe/cloudpickle .
8. No claim that a generated evaluation case is human-reviewed. Maintain a separate frozen held-out regression corpus with transparent deterministic labels and genuine negative/unknown/adversarial cases; independent reviewer checks are agent review, not owner approval. Live model results never inherit another model's thresholds.
